## 后端服务错误修复
- **根因**：`users` 表缺少 `email` 列，导致所有引用 `u.email` 的 JOIN 查询报 `ER_BAD_FIELD_ERROR`
- **原因**：db.js 迁移用了 `ALTER TABLE users ADD COLUMN IF NOT EXISTS email...`，但 MySQL 不支持 `IF NOT EXISTS` 语法（这是 MariaDB 特有），迁移静默失败
- **修复**：
  1. 手动执行 `ALTER TABLE users ADD COLUMN email VARCHAR(100) DEFAULT NULL` 添加缺失字段
  2. 修改 db.js 迁移逻辑，用 try/catch + `ER_DUP_FIELDNAME` 错误码判断，兼容 MySQL
- **影响模块**：人员管理、打卡记录、信息通知、考勤组管理（用户列表查询被 email 字段阻断，通知/考勤组无数据但不报错）
- **验证**：所有4个模块的 SQL 查询均通过
