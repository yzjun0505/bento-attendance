## 地图看板初始定位优化
- **问题**：地图看板每次打开默认显示天安门，等 GPS 定位完成（几秒）后才跳到用户位置
- **根因**：AMapWebView 初始化时 `initLng/initLat` 为 null（bloc 还没拿到 GPS），高德地图 JS API 默认中心点为北京
- **修复**（map_dashboard_screen.dart）：
  1. `initState` 中调用 `Geolocator.getLastKnownPosition()` 获取设备缓存的最后已知位置（瞬间返回）
  2. WGS84→GCJ02 坐标转换后存入 `_cachedLat/_cachedLng`
  3. `build` 方法中 `initLng/initLat` 回退到缓存位置
  4. `_syncAll` 中 GPS 获取成功后更新缓存位置，bloc 还没拿到 GPS 时也用缓存位置移动地图

## 水印拍照定位失败 + 周边地址列表修复
- **问题1**：水印拍照界面定位一直失败，显示"定位中..."
- **问题2**：点击地址字段后无法打开周边地址列表，或者列表为空
- **根因**：
  1. `_initGeo()` 使用 `forceAndroidLocationManager: true` 强制 Android 原生 LocationManager，在某些设备上定位失败
  2. `_loadNearbyPlaces()` 加载了高德周边搜索结果，但结果没有保存到状态变量中，导致列表为空
  3. `_openLocationPicker()` 在 `_latitude/_longitude` 为 null 时直接 return，用户点击无响应
- **修复**（camera_checkin_screen.dart）：
  1. 移除 `forceAndroidLocationManager: true`，改用 FusedLocationProvider（更可靠）
  2. 增加超时到 15 秒，失败时先用 `getLastKnownPosition()` 回退
  3. 新增 `_retryLowAccuracyGeo()` 低精度回退方法
  4. 从 AttendanceBloc 回退后，如果 bloc 有位置也执行逆地理编码和周边搜索
  5. 新增 `_nearbyPlaces` 状态变量，`_loadNearbyPlaces()` 把结果保存到其中
  6. `_openLocationPicker()` 没有坐标时先尝试重新定位，而不是直接 return
  7. `_LocationPickerScreen` 新增 `preloadedPlaces` 参数，传入已加载的地址列表，一打开就能直接显示

## 水印字段编辑不生效修复
- **问题**：编辑水印字段（如打卡名称）后，相机上的水印文字没有更新，保持模板默认值
- **根因**：`_getSlotValue` 中 `customText`（模板硬编码文字）优先级高于用户数据，导致编辑无效
- **修复**（camera_checkin_screen.dart）：
  1. `_getSlotValue` 改为数据优先：先从 data Map 读取用户编辑后的值，只有为空时才回退到模板默认文字
  2. `_editTextfield` 改为 `Future<void>` 异步方法，用 `showDialog<String>()` 返回结果
  3. `_editTemplateField` 正确 `await` 编辑对话框

## 水印主标题被项目名称覆盖修复
- **问题**：打卡名称设为"项目进度上报"，但水印主标题仍显示"一层地面"
- **根因**：`_syncTitleToTemplate()` 只改了 `titleSlot.customText`，但 `binding='project'` 仍在，`_getSlotValue` 优先级 `binding > customText`
- **修复**：
  1. `_syncTitleToTemplate()` 清空 `binding`，同步 `label` 和 `customText` 为 `_watermarkTitle`
  2. 编辑打卡名称时统一调用 `_syncTitleToTemplate()`

## 水印设置面板字段与水印预览不一致修复

  1. 新增 `_getSlotDisplayValue(WatermarkSlot)`，与水印预览取值逻辑完全一致
  2. 重构 `_showWatermarkEditPanel`："当前模板字段"部分改为遍历 `subtitleSlot` + `contentSlots`
  3. 每个字段的 label 直接使用 `slot.label`，value 使用 `_getSlotDisplayValue(slot)`
  4. 新增 `_buildWatermarkSettingRowForSlot()` 辅助方法
  5. 兜底逻辑 `_buildDefaultWatermarkSettingRows()` 仅在模板未加载时使用

## P1 功能模块实现（2026-04-28 晚）
### 1. 排班/班次管理
- **新增表**：`shifts`（班次表）、`user_schedules`（排班表）
- **默认班次**：白班(08:00-17:00)、早班(06:00-14:00)、晚班(14:00-22:00)、夜班(22:00-06:00)
- **API**：班次CRUD `/api/shifts`，排班批量设置 `/api/schedules/batch`，日历视图 `/api/schedules/calendar`，今日排班 `/api/schedules/today`
- **控制器**：`shiftController.js`、`scheduleController.js`
- **路由**：`shifts.js`、`schedules.js`

### 2. 节假日/工作日设置
- **新增表**：`holidays`（节假日表）
- **API**：节假日CRUD `/api/holidays`，批量导入 `/api/holidays/batch`，日期检查 `/api/holidays/check`
- **类型**：`holiday`（放假）、`workday`（调休上班）
- **控制器**：`holidayController.js`
- **路由**：`holidays.js`

### 3. 请假/加班审批流（增强）
- **审批通过联动考勤**：
  - 补卡 → 对应日期 `attendance_results.status = 'normal'`
  - 请假 → 日期范围 `status = 'leave'`
  - 加班 → 日期范围标记 `overtime = 1`
- **修复**：`approvalController.js` 日期格式化改用本地时间 `formatLocalDate()`，避免 UTC 偏移问题
- **修复**：所有 `console.error` 改为 `logger.error`

### 4. 离线打卡
- **新增表**：`offline_checkins`（离线打卡缓存表）
- **流程**：移动端无网络时 → 缓存到本地 → 有网后调用 `/api/offline-checkins/sync` 同步到正式打卡表
- **API**：提交缓存 `/api/offline-checkins`，获取记录 `/api/offline-checkins/mine`，同步 `/api/offline-checkins/sync`
- **控制器**：`offlineCheckinController.js`
- **路由**：`offlineCheckins.js`

### 5. 轨迹回放
- **API**：个人轨迹 `/api/tracks/:userId?date=YYYY-MM-DD`，热力图 `/api/tracks/heatmap`
- **功能**：合并 `locations` + `checkins` 位置数据，按时间排序，计算总距离，自动检测停留点（距离<50米且时长>5分钟）
- **控制器**：`trackController.js`
- **路由**：`tracks.js`
