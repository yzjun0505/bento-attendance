## 修复 IM 登录 10009 错误（SDK login incomplete）

**问题**：OpenIM SDK v3.8 的 `login()` 方法内部在原生登录后会立即调用 `getSelfUserInfo()` 获取用户信息作为返回值。但 v3 的登录是异步的——原生层返回后 SDK 还在同步数据，此时调 `getSelfUserInfo` 触发 `10009 SDK login incomplete` 错误。

**修复**（`openim_service.dart`）：
- `login()` 方法传入 `defaultValue: () async => UserInfo(userID: userID)` 绕过 SDK 内部的 `getSelfUserInfo` 调用
- `login()` 方法传入 `checkLoginStatus: false` 强制重新登录
- 新增 `_loginCompleter` 字段，在 `login()` 中创建 Completer
- 通过 `OnConnectListener.onConnectSuccess` 回调来真正确认登录完成（complete(true)）
- 通过 `OnConnectListener.onConnectFailed` 回调确认登录失败（complete(false)）
- `login()` 等待 Completer 最多 15 秒，超时返回 false
- `reset()` 方法清理 `_loginCompleter`

## 修复 IM 登录 10006 错误（数据库文件无法打开）

**问题**：`login()` 时报 `10006 Internal SDK error: unable to open database file: no such file or directory /data/user/0/.../openim/OpenIM_v3_2.db`

**根因**：OpenIM SDK 的 `initSDK()` **不会自动创建数据库目录**。`login()` 时 Go 层尝试在 `dataDir/openim/` 下创建 SQLite 数据库，但该目录不存在。

**验证**：`adb shell run-as com.example.mobile_app ls app_flutter/` 显示没有 `openim` 子目录。

**修复**：
- `openim_service.dart`：在 `initSDK()` 之前用 `Directory.create(recursive: true)` 确保数据库目录存在
- `openim_service.dart`：`reset()` 方法增加调用 `OpenIM.iMManager.unInitSDK()` 清理 Go 层状态
- `conversation_list_screen.dart`：重试按钮不再盲目 `reset()` + 重新 `init()`，如果 SDK 已初始化则直接 `login()`
- `auth_bloc.dart`：`_onLoggedOut` 增加 `_imService.reset()` 清理 SDK 状态，确保下次登录可以重新初始化

## 修复 IM 消息收发 + 联系人显示问题

**问题 1：高启强看不到联系人**
- 根因：IM 连接成功后 `_loadIMData()` 立即调用，但 SDK 还在后台同步好友数据
- 修复：连接成功后延迟 2s 和 5s 各加载一次数据
- `getFriendList()` 增加详细调试日志

**问题 2：消息收不到**
- 根因：`ChatScreen` **完全没有监听 `messageStream`**！`onRecvNewMessage` 回调把消息放到了 `_messageController` stream，但 ChatScreen 没有订阅
- 修复：`ChatScreen` 增加 `_messageSubscription`，在 `initState` 中订阅 `_imService.messageStream`
- 判断逻辑：用 `widget.isGroup` 区分单聊/群聊，匹配 `receiverId`

**问题 3：聊天列表不实时更新**
- 根因：`HomeScreen` 没有监听会话变化和新消息
- 修复：订阅 `conversationStream` 和 `messageStream`，通过防抖（500ms）触发 `_loadIMData()`
- dispose 时取消所有 stream 监听
