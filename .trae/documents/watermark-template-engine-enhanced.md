# 水印模版引擎 (Watermark Template Engine) 增强计划

## 1. 总结 (Summary)
在原本“版式骨架库 + 插槽数据与权限绑定”的基础上，进一步增强系统的拓展性。允许管理员在现有的版式骨架上**新增自定义插槽 (Custom Slots)**，并允许在模板基础信息中**动态新增分类 (Category)**。这些自定义数据将随着 `schema` 和 `category` 字段同步至后端，从而实现与手机端打卡界面的无缝联动。

## 2. 当前状态分析 (Current State Analysis)
- `Watermarks.vue` 已经实现了基础的“骨架 + 插槽”逻辑，但插槽是固定写死在各个 `layout` 定义中的。
- “分类 (Category)”使用的是静态的 `<el-select>` 选项（日常打卡、工程记录等），无法应对未来新的业务场景。

## 3. 拟定更改 (Proposed Changes)

### 3.1 动态新增插槽 (Custom Slots)
- **修改内容**：在右侧面板“插槽配置”底部增加“+ 新增自定义插槽”按钮。
- **数据结构**：在 `currentConfig.schema` 中增加 `customSlots: [{ id, label }]` 数组，用于记录额外添加的插槽。
- **渲染逻辑**：
  - 右侧面板：遍历 `[...基础插槽, ...自定义插槽]`，提供统一的数据绑定与权限控制。
  - 中间画布：对于每种骨架（如 `pure_text`, `glass_card`, `stamp`, `polaroid`），指定一个自适应区域用于渲染新增的插槽内容（例如：纯文本追加在底部，卡片追加在文本区下方等）。

### 3.2 动态新增分类 (Custom Category)
- **修改内容**：将左侧面板的“分类 (Category)”选择器开启允许创建新条目的功能。
- **具体实现**：为 `<el-select>` 添加 `allow-create` 和 `filterable` 属性。用户可以直接输入新的分类名称并回车，该值将作为 `category` 存入数据库。

### 3.3 手机端同步逻辑
- 后端接口无需变更。前端将自定义分类名称通过 `category` 字段提交，将自定义插槽定义及配置通过 `schema_json` 提交。手机端获取列表时，只需按 `category` 分组，并按 `schema_json` 中的插槽组合渲染即可。

## 4. 假设与决定 (Assumptions & Decisions)
- **决定**：自定义插槽的 ID 采用 `custom_` + 时间戳的格式，确保唯一性。
- **决定**：当切换左侧版式骨架时，已创建的自定义插槽将被保留，并自动映射到新骨架的展示区域，防止用户配置丢失。

## 5. 验证步骤 (Verification Steps)
1. 在左侧面板的“分类”中输入一个全新的词汇（如“活动展会”），确认能够成功选中。
2. 在右侧面板点击“新增自定义插槽”，输入名称并确认，观察列表中是否出现新插槽配置项。
3. 为新插槽绑定“自定义文本”并输入内容，观察中间手机画布是否实时渲染出该行文字。
4. 点击“保存入库”，并重新编辑该模板，验证自定义插槽和分类是否成功回显。
